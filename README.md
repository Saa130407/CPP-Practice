# Contact Management System

A simple C++ console program to manage contacts.

## Features

- Add a contact
- Display all contacts
- Search for a contact by name
- Update contact details
- Delete a contact
- Exit the program

## Contact Details

Each contact stores:

- Name
- Phone number
- Email address

## Menu Options

1. Add Contact  
2. Display Contacts  
3. Search Contact  
4. Update Contact  
5. Delete Contact  
6. Exit  


```bash
g++ contact_management.cpp -o contacts
./contacts
